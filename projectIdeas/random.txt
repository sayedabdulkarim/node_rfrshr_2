 Top 3 Extension Ideas (download potential ke hisaab se):

  1. "CodePulse" — AI Code Attribution Tracker (BEST BET)

  - Kya: Track karo kaunsa code AI ne likha (Copilot/Claude) aur kaunsa tune likha. Inline annotations (GitLens jaisa but for AI). Dashboard showing AI vs human code percentage.
  - Kyun: 84% devs AI use kar rahe, but koi nahi track kar raha "ye code kisne likha?" — brand new category, ZERO competition
  - Audience: Millions (har Copilot/Claude user)
  - Press coverage bhi milega — AI accountability hot topic hai

  2. "FocusFlow" — Anti-Context-Switch Workspace Manager

  - Kya: One-click "context snapshot" — open files, cursor positions, terminal state sab save/restore. Focus timer + interruption stats.
  - Kyun: Devs 13x/hour context switch karte, 20+ min waste hota. Universal pain point. Existing solutions basic hain.
  - Audience: Literally every VS Code user (14M+)

  3. "ShieldCheck" — Inline Security Scanner (Free, No Sign-up)

  - Kya: Lightweight security scanner — hardcoded secrets catch karo, injection patterns, insecure dependencies. As you type.
  - Kyun: Enterprise tools exist (Snyk, Aikido) but individual devs ke liye koi simple free option nahi. Shift-left security trending hai.
  - Audience: Solo devs, students, small teams
