# MongoDB Interview Questions (Beginner to Intermediate)

## BEGINNER LEVEL

## 1. What is MongoDB? How is it different from SQL databases?

  MongoDB is a NoSQL document-oriented database that stores data in JSON (JavaScript Object Notation )-like documents (BSON ( Binary JSON) format).

  Key Differences from SQL:

  | SQL Databases                     | MongoDB                       |
  |-----------------------------------|-------------------------------|
  | Tables                            | Collections                   |
  | Rows                              | Documents                     |
  | Columns                           | Fields                        |
  | Fixed schema                      | Flexible schema               |
  | JOIN operations                   | Embedded documents or $lookup |
  | Vertical scaling                  | Horizontal scaling (sharding) |
  | ACID transactions (traditionally) | ACID transactions (4.0+)      |


## 2. What is a document in MongoDB?


  A document is a record in MongoDB, similar to a row in SQL. It's stored in BSON (Binary JSON) format.

  Example from your code (server/models/Todo.js:1-30):
  {
    _id: ObjectId("507f1f77bcf86cd799439011"),
    user: ObjectId("507f191e810c19729de860ea"),
    text: "Buy groceries",
    completed: false,
    createdAt: ISODate("2025-01-15T10:30:00Z"),
    updatedAt: ISODate("2025-01-15T10:30:00Z")
  }

## 3. What is a collection in MongoDB?

A collection is a group of documents, similar to a table in SQL. Collections don't enforce a schema by default (flexible
  structure).

  In your app, you have 3 collections:
  - users - Stores user accounts
  - todos - Stores todo items
  - roles - Stores role definitions with permissions

## 6. What is Mongoose? Why do we use it?

 Mongoose is an ODM (Object Data Modeling) library for MongoDB and Node.js.

  Benefits:
  - Schema validation
  - Middleware/hooks (pre/post operations)
  - Built-in type casting
  - Query building helpers
  - Relationship management (populate)
  - Data validation

  In your app: You use Mongoose for all database operations, with schemas for User, Todo, and Role models.

## 7. How to create a schema in Mongoose?

const mongoose = require('mongoose');

  const userSchema = new mongoose.Schema({
    name: {
      type: String,
      required: true,
    },
    createdAt: {
      type: Date,
      default: Date.now,
    },
  });

  const User = mongoose.model('User', userSchema);

## 8. What are the basic CRUD operations in MongoDB?

  CRUD = Create, Read, Update, Delete

  | Operation | MongoDB Method            | Mongoose Method                              |
  |-----------|---------------------------|----------------------------------------------|
  | Create    | insertOne(), insertMany() | Model.create(), new Model().save()           |
  | Read      | find(), findOne()         | Model.find(), Model.findById()               |
  | Update    | updateOne(), updateMany() | Model.findByIdAndUpdate(), Model.updateOne() |
  | Delete    | deleteOne(), deleteMany() | Model.findByIdAndDelete(), Model.deleteOne() |

## 14. What is the difference between MongoDB and MySQL?

14. MongoDB vs MySQL

  | Feature        | MongoDB                             | MySQL                            |
  |----------------|-------------------------------------|----------------------------------|
  | Type           | NoSQL (Document DB)                 | SQL (Relational DB)              |
  | Data Storage   | Collections → Documents (JSON/BSON) | Tables → Rows                    |
  | Schema         | Flexible (schema-less)              | Fixed (strict schema)            |
  | Relationships  | Embedded docs or $lookup            | JOINs (foreign keys)             |
  | Scaling        | Horizontal (sharding)               | Vertical (bigger server)         |
  | Query Language | MongoDB Query Language              | SQL                              |
  | ACID           | Yes (4.0+, single doc always)       | Yes (full support)               |
  | Use Case       | Flexible data, rapid changes        | Structured data, complex queries |
  | Performance    | Fast reads/writes (denormalized)    | Fast with proper indexing        |
  | Example        | User profiles, logs, real-time      | Banking, inventory, accounting   |

## 16. What is Redis?
   Redis is an in-memory key-value database (NoSQL) used primarily for caching.
   - We use Redis for cache data only, not for original database
   - Data stored in RAM (super fast but expensive)
   - In case server restarts, we lose all Redis data (unless persistence enabled)
   - MongoDB = Permanent storage, Redis = Temporary cache

## 19. What are MongoDB data types?

MongoDB supports various BSON data types:

| Data Type     | Description                          | Example                              |
|---------------|--------------------------------------|--------------------------------------|
| String        | UTF-8 text                           | `"Hello World"`                      |
| Integer       | 32-bit or 64-bit numbers             | `42`, `NumberInt(42)`                |
| Double        | 64-bit floating point                | `3.14`                               |
| Boolean       | true or false                        | `true`, `false`                      |
| ObjectId      | 12-byte unique identifier            | `ObjectId("507f1f77bcf86cd799439011")` |
| Date          | Date/time in milliseconds            | `ISODate("2025-01-15T10:30:00Z")`    |
| Array         | List of values                       | `["apple", "banana", "cherry"]`      |
| Object        | Embedded document                    | `{ name: "John", age: 30 }`          |
| Null          | Null/empty value                     | `null`                               |
| Binary Data   | Binary data (images, files)          | `BinData(0, "base64string")`         |
| Decimal128    | High-precision decimal               | `NumberDecimal("19.99")`             |
| Timestamp     | Internal MongoDB timestamp           | `Timestamp(1234567890, 1)`           |
| RegExp        | Regular expression                   | `/pattern/i`                         |


**Note:** Empty databases (with no collections) won't show in the list.
