- difference between js and nodejs
    Key Differences:

  | Feature    | JavaScript               | Node.js             |
  |------------|--------------------------|---------------------|
  | Type       | Language                 | Runtime Environment |
  | Runs on    | Browser                  | Server/Computer     |
  | Can access | DOM, Window              | File System, OS     |
  | Used for   | Frontend                 | Backend             |
  | Example    | document.querySelector() | fs.readFile()       |
